# Biodiversity in National Parks Analysis Dashboard

## Project Overview

This project focuses on analyzing and visualizing biodiversity information across different national parks using Tableau.

The dashboard provides insights into species distribution, biodiversity across parks, conservation status, nativeness classifications, and the relationship between park area and recorded species diversity.

## Objectives

- Analyze species distribution across different biological categories.
- Compare biodiversity across national parks.
- Visualize the geographical distribution of national parks.
- Examine species conservation status.
- Analyze nativeness classifications.
- Study the relationship between park area and recorded species diversity.

## Tools and Technologies

- Tableau Desktop – Data visualization and dashboard development.
- CSV – Dataset storage.
- GitHub – Project version control and sharing.

## Datasets

Two datasets are used:

1. `parks.csv` – Contains park names, park codes, states, geographical coordinates, and area information.
2. `species.csv` – Contains species records, biological categories, scientific names, conservation status, and nativeness information.

## Dashboard Visualizations

The project includes:

- KPI indicators
- Species by Category
- Species by Park
- Park Biodiversity Map
- Conservation Status
- Nativeness Analysis
- Nativeness Percentage
- Area vs Biodiversity Scatter Plot
